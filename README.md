# ⚠️ Project Status: Archived

Koseven is no longer actively maintained and has been archived.

# Why?

Koseven started as a community effort to extend the life of the Kohana framework after its official end-of-life. Its primary goal was to help developers transition legacy applications to PHP 7 and buy time for migration.

That goal has long been fulfilled.

Over the years, the PHP ecosystem has evolved significantly, and modern frameworks such as [Laravel](https://laravel.com/) now provide better performance, security, and long-term support. Like many others, the maintainers have moved on to these actively maintained ecosystems.

# Current State
- No active development
- No guaranteed compatibility with newer PHP versions (8+)
- Issues and pull requests are no longer regularly reviewed
- Security fixes are not guaranteed

What this means for you:

If you are still running Koseven in production, it is strongly recommended to plan a migration to a modern, actively maintained framework.

Koseven was never intended to be a long-term solution — it was a bridge.

# Community & Contributions

This project lived far longer than expected thanks to its contributors.

To everyone who opened issues, submitted pull requests, fixed bugs, or helped others — thank you. Your work kept Koseven relevant well beyond its original purpose.
